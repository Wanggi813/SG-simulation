지난 시간 순차 측정 시뮬레이션 결과

실험 분석기 배치 결과
①z↑ → z모두 z↑
②z↑ → xx+, x− 반반
③z↑ → x+ → z마지막 z가 다시 반반 (측정이 상태를 바꾼다)
시뮬레이션 → 양자컴퓨터 번역표

0 = z↑, 1 = z↓ · 큐비트는 |0⟩(z↑)에서 시작해요.

분석기를 x쪽으로 돌리는 대신, 큐비트를 반대로 90° 돌리고(RY(−90°)) z로 측정해요.

순차 측정 시뮬레이션 양자컴퓨터 회로
처음 z 확인측정
z축 분석기측정
x축 분석기RY(−90°) → 측정  (0 = x+, 1 = x−)
x 측정 뒤 원래 자리로RY(+90°)
결과 문자열 읽는 법 왼쪽부터 = 측정 순서

측정 결과는 c[0] → c[1] → c[2]에 차례로 저장하고, c[3]은 비워 둬요.

예: ③의 0110 = 첫 0(z↑) → 둘째 1(x−) → 셋째 1(z↓) · ①·②는 오른쪽 두 자리가 늘 00

⚠ 실행 결과 히스토그램은 c[0]이 맨 왼쪽이에요. (실행 전 회로 화면에서는 맨 오른쪽)

Composer 회로 만들기 팁
  • 큐비트 q[0] 하나, 고전 레지스터 c는 4비트
  • 측정은 c[0] → c[1] → c[2] 순서로 연결 (c[3]은 비움)
  • RY 각도: −π/2(−90°), π/2(+90°)
  • 확인: Bit-by-bit outcomes 탭에서 c[0]은 거의 0, c[3]은 늘 0

결과마다 몇 %가 나올지 예측해요. 합은 100%, 다음으로 넘어가면 잠겨요.

③ 결과 입력

실제 QPU로 실행한 뒤, 히스토그램의 결과별 횟수를 보이는 그대로 적어요. 비율은 자동 계산돼요.

1~2회짜리 작은 막대도 빠짐없이 적고, 없는 결과는 0으로 둬요.

맨 오른쪽이 1인 결과(예: 0001)가 보이면?

c[3]에 측정이 연결된 거예요. 회로를 확인하고 선생님께 알려 주세요.

확률(%)만 보이면?

확률 × shots를 반올림해 적어요. 예: 0.95 × 1024 ≈ 973
